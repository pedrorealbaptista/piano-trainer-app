Piano Tab Trainer - installable web app

HOST IT (pick one, both free)
  Netlify Drop: go to app.netlify.com/drop and drag this whole folder onto the page.
                You get an https link straight away (a free account keeps it permanent).
  GitHub Pages: put these files in a repo, then Settings > Pages > deploy from the main branch.

INSTALL ON IPHONE
  1. Open your link in Safari.
  2. Tap Share, then "Add to Home Screen".
  3. Open it from the new icon. It runs full screen, and after the first launch it also works offline.

TIPS
  - No sound? Turn off the silent switch on the side of the iPhone.
  - Save .mid or .txt tabs to the Files app, then use "Open a file" in the trainer.
  - Turn the phone sideways to see more of the keyboard.
